# SPORT DAY

Mobile-first маршрут для школьного Sport Day. Сайт не требует регистрации и сохраняет текущую станцию каждого класса в браузере телефона.

Интерфейс работает на русском и эстонском языках. Выбранный язык сохраняется на телефоне.

Результаты также сохраняются на телефоне отдельно для каждого класса:

- очки баскетбола — кнопки `−1`, `−3`, `+1`, `+3`;
- футбольные голы — `−1` и `+1`;
- общая дистанция прыжков — в метрах;
- задания на скорость — минуты и секунды;
- остальные задания — отметка о выполнении.

Все результаты видны на странице маршрута класса.

## Запуск

```bash
npm start
```

Откройте `http://localhost:4173`.

## Публикация на Vercel

Проект собирается как полностью статический сайт:

```bash
npm run build
```

Vercel автоматически использует команду сборки и папку `dist` из `vercel.json`. Серверных функций в production нет.

## Где менять данные

Все маршруты и содержимое станций находятся в `data.js`:

- `classes` — названия, цвета и порядок станций;
- `stations` — название, описание, время, инвентарь и видео на русском (`ru`) и эстонском (`et`).

Для YouTube используйте embed-ссылку, например:

```js
video: "https://www.youtube.com/embed/VIDEO_ID"
```

## Прямые ссылки для QR-кодов

- `/class/1a`
- `/class/1b`
- `/class/1h`
- `/class/1el`

При публикации настройте перенаправление неизвестных адресов на `index.html` (SPA fallback). Для Vercel это уже настроено в `vercel.json`.
