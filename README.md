# SPORT DAY

Mobile-first маршрут для школьного Sport Day. Сайт не требует регистрации и сохраняет текущую станцию каждого класса в браузере телефона.

Интерфейс работает на русском и эстонском языках. Выбранный язык сохраняется на телефоне.

Результаты также сохраняются на телефоне отдельно для каждого класса:

- очки баскетбола — кнопки `−1`, `−3`, `+1`, `+3`;
- футбольные голы — `−1` и `+1`;
- общая дистанция прыжков — в метрах;
- задания на скорость — минуты и секунды;
- остальные задания — отметка о выполнении.

Все результаты видны на странице маршрута класса.

Общий таймер запускается автоматически при открытии первой станции маршрута и останавливается кнопкой завершения на последней станции. На заданиях 5 и 6 учитель самостоятельно нажимает `START` и `STOP`; нажатие `STOP` сразу сохраняет время в итоговый отчёт.

## Supabase

1. Создайте проект Supabase и выполните содержимое `supbase/schema.sql` в SQL Editor.
2. Для локальной сборки заполните `supbase/key`:

```env
SUPABASE_URL=https://YOUR_PROJECT.supabase.co
SUPABASE_ANON_KEY=YOUR_PUBLIC_ANON_KEY
```

Используйте только публичный `anon` / publishable key. Никогда не добавляйте `service_role` key в сайт.

3. В Vercel → Project Settings → Environment Variables добавьте те же переменные:

- `SUPABASE_URL`
- `SUPABASE_ANON_KEY`

4. Выполните Redeploy without cache.

При настроенном Supabase прогресс, общий таймер, таймеры станций и результаты синхронизируются между телефонами каждые 5 секунд. Файл `supbase/key` исключён из Git.

## Запуск

```bash
npm start
```

Откройте `http://localhost:4173`.

## Публикация на Vercel

Проект собирается как полностью статический сайт:

```bash
npm run build
```

Vercel автоматически использует команду сборки и папку `dist` из `vercel.json`. Серверных функций в production нет.

## Где менять данные

Все маршруты и содержимое станций находятся в `data.js`:

- `classes` — названия, цвета и порядок станций;
- `stations` — название, описание, время, инвентарь и фотография на русском (`ru`) и эстонском (`et`).

Фотографии и схемы заданий хранятся в папке `assets`. Чтобы добавить фотографию станции, укажите путь:

```js
photo: "/assets/station-1.jpg"
```
